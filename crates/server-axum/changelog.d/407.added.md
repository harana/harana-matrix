Add the `server-axum` crate, which defines every route a Matrix homeserver has
to answer as an axum router, derived from the endpoint metadata of the Ruma
crates: all client-server and server-server endpoints, each on every path it
has ever had, with the HTTP method, authentication scheme and rate limiting the
specification gives it. It carries no server logic; endpoints a server has not
implemented answer `404 M_UNRECOGNIZED`, and handlers are attached to them with
the `Ruma` extractor and the `RumaResponse` wrapper.
