`Backups::wait_for_steady_state()` now only observes the upload task; use the
new `Backups::trigger_upload()` to make it run. Awaiting the future used to
start an upload despite reading as a passive wait. The wait also no longer
returns on the first `Done` it sees: it checks that the store has nothing left
to upload, so room keys queued during the call are covered rather than skipped.
`WaitForSteadyState::with_delay()` applies the delay immediately instead of when
the future is first polled.
