The media service now reports download progress, alongside the upload progress
it already exposed. `Media::get_media_content_with_progress` takes an observable
that the transfer is reported into, so a client can show a progress indicator
for an attachment; `SendRequest::subscribe_to_receive_progress` does the same
for any request. Nothing is reported when the content comes back from the media
cache, and a response with no `Content-Length` has no known total, so `total`
tracks `current` until the download ends.

`HttpSend` gained `send_request_with_progress`, which is what the SDK now calls.
It has a default implementation forwarding to `send_request` and reporting no
download progress, so existing transports keep working unchanged; the `reqwest`
transport overrides it and reads the response body in chunks, but only while
something is subscribed. `MediaFetcher` gained
`fetch_media_content_with_progress` on the same terms.
