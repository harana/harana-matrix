`ClientBuilder::discovery_cache_timeout` sets how long a cached discovery
result (the homeserver's well-known file, its supported Matrix versions, its
capabilities and its RTC transports) stays usable before it is fetched again.
It defaults to `Client::DEFAULT_DISCOVERY_CACHE_TIMEOUT`, one day, which is
what the built-in threshold used to be.

`Client::rediscover` discards every cached discovery result and fetches it
again through the normal outgoing request path, for a client that knows better
than a timer when the server's configuration changed. Unlike the background
refresh a stale read starts, it awaits the fetches.
