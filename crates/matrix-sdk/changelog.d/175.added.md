`Room::send_single_receipt()` now applies an unthreaded or main-threaded read
receipt locally as soon as it is sent, instead of leaving the room showing as
unread until the receipt comes back through sync, which on a slow connection or
a busy homeserver takes long enough to look broken. The echo goes through the
same computation a synced receipt does, so the receipt arriving later is a
no-op; if the request fails, the echo is rolled back, unless a sync changed the
read receipts in between.
