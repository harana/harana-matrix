`Backups::reconcile_with_server()` brings the local backup state in line with
the homeserver, disabling backups locally when the version we hold a key for is
no longer the current one. `Recovery::enable_backup()` reconciles first, so a
backup deleted and recreated by another client no longer leaves the SDK
reporting backups as enabled, and re-enabling a backup we are already connected
to succeeds instead of failing with `BackupExistsOnServer`.
