Add `AttachmentConfig::strip_exif`, which removes the metadata embedded in an
image before it is uploaded. A photo straight off a phone carries an Exif block
holding the GPS coordinates and wall-clock time of the shot, the device model
and sometimes its serial number; with this set, that block and the other
metadata containers (XMP, IPTC, PNG text chunks, JPEG comments) are removed from
the attachment and from its thumbnail. The Exif `Orientation` tag is kept, so
photos are still displayed the right way up, and the pixels are never
re-encoded, so this costs no image quality. It applies to JPEG, PNG and WebP;
any other attachment is uploaded unchanged. Off by default.
