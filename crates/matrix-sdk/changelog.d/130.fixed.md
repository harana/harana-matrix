A message whose body is only an ordered list marker, e.g. `5.`, is no longer
sent with a formatted body. Markdown parses it as a list item with no content,
so the HTML carried no text and clients rendering the formatted body showed a
bare list marker instead of what was typed. The new
`matrix_sdk::utils::markdown_formatted_body()` applies this check, and
`formatted_body_from()` uses it.
