The per-room, per-session and version-management key backup endpoints are now
reachable from `Backups`: `info_for_version`, `update_version_auth_data`,
`upload_room_keys_for_room`, `upload_room_key`, `delete_all_room_keys`,
`delete_room_keys_for_room` and `delete_room_key`. Uploads were only possible in
bulk, backed-up keys could not be deleted at any granularity, and only the
latest backup version could be inspected.
