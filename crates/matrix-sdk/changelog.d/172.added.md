`OAuth::migrate_matrix_session()` turns a session of the native Matrix
authentication API into an OAuth 2.0 session, for a homeserver that moved to an
authentication server after the session was created. It registers client
credentials with the authentication server and restores the existing tokens as
an OAuth 2.0 session, returning it so the caller can store it in place of the
old one; a homeserver without an authentication server fails the call with
`OAuthDiscoveryError::NotSupported` without touching the client. Restoring such
a session previously kept using the legacy API, which cannot reach the account
management URLs of the authentication server.
