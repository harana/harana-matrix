Ignoring a user no longer clears the event cache of every room. It wiped the
previews of rooms the ignored user had nothing to do with, and left the room
list ordering mixing latest-event timestamps with recency stamps; unignoring
restored nothing. Only the rooms the newly ignored user takes part in are
cleared now, and the latest event of every room is recomputed when the ignore
list changes, in both directions.

`EventCacheStore::clear_all_events` for a single room used to reset the
in-memory linked chunks of *all* the rooms and propagate that reset to the
store, so clearing one room emptied every other one. Only the room being
cleared forgets its events now.
