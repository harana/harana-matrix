The crate documentation now says which Matrix specification version the SDK's
types target (v1.19), how a `Client` probes `/_matrix/client/versions` and
caches the answer, and how the request path adapts to it: endpoint versions,
the choice between an old and a new way of doing the same thing, and room
version rules.

`Client::supports_endpoint` answers whether the homeserver advertises support
for one endpoint, either through a Matrix version or the unstable feature flag
it shipped behind. The SDK already made that check in a handful of places by
hand; it is now one call, and available to callers making the same choice.
