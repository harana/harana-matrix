A message whose body markdown reads as list markup carrying no content at all,
such as a bare `5.`, is no longer converted to HTML. Such a body became an
empty `<li>` whose marker the receiving client renumbers, so `5.` arrived as
`1.`; it is now sent as plain text. Lists with content, such as `5. buy milk`,
are unaffected. `client_matrix::utils::formatted_body_from_markdown` applies this
and should be preferred over `FormattedBody::markdown`.
