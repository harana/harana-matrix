The event cache can now delete the events that fall outside a room's message
retention policy ([MSC1763](https://github.com/matrix-org/matrix-spec-proposals/pull/1763)),
along with the local media they refer to.
`EventCache::purge_expired_events` sweeps every loaded room, fetching the
server's retention configuration once;
`RoomEventCache::purge_expired_events` applies one room's effective policy; and
`RoomEventCache::purge_events_older_than` applies a lifetime of the caller's
choosing. None of them is scheduled: purging deletes the user's messages, so
when a sweep happens is left to the caller.
