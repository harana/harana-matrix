`Client::restore_session_with_access_token()` and
`MatrixAuth::restore_session_with_access_token()` restore a session from an
access token alone, discovering the user ID and device ID with `whoami`.
Restoring previously required the caller to have cached the `SessionMeta`. The
restored `MatrixSession` is returned so it can be persisted for next time.
Fails with the new `Error::MissingDeviceId` when the homeserver's `whoami`
response carries no device ID: the field is optional in the specification, but
the SDK needs one to identify the device owning the encryption keys.
