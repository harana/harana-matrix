`Client::server()` has been renamed to `Client::server_name()` and now returns
an `Option<OwnedServerName>` instead of an `Option<Url>`. It previously returned
a URL such as `https://matrix.org/` where the documentation described a Matrix
server name. Once the client is logged in, the value is derived from the
session's user ID; before that, it is the name the client was built from, and
`None` when it was built from a homeserver URL.
