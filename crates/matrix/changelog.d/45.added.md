Add `AttachmentConfig::generate_blurhash`, which computes the
[BlurHash](https://blurha.sh/) of an image being uploaded and puts it in the
media event's content, so receiving clients can render a blurred placeholder
while the media downloads. An image is hashed from its own data and a video
from its thumbnail, since the SDK has no video decoder; a BlurHash already
present in the attachment info is left alone. It requires the new `image-proc`
feature, which pulls in an image decoder, and is off by default.
