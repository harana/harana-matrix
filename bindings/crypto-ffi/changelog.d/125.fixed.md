Building for Android no longer fails with a confusing "no C compiler found"
from the bundled SQLite build when only the linker is configured. The Kotlin
xtask now checks that an NDK is configured (`ANDROID_NDK_HOME`,
`ANDROID_NDK_ROOT` or `ANDROID_NDK`) before building and says what to set
otherwise, and the README documents the full toolchain environment, `CC` and
`AR` included, for a build driven by cargo directly.
