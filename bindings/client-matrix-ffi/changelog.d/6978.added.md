Added `pluggable::TelemetryProvider`, which contributes an extra `tracing`
layer to the subscriber the bindings install, so an application embedding these
bindings from Rust can send the SDK's spans and events to an OpenTelemetry
pipeline or its own log shipper alongside the built-in text and Sentry sinks.
Install providers with `pluggable::set_telemetry_providers` before
`init_platform`.

Added `pluggable::ClientBuilder::custom_store`, which uses a session store of
your own instead of SQLite, IndexedDB or the in-memory store.

The event cache store's log target is now taken from whichever store backend
the bindings were built with, rather than being a hard-coded module path.
