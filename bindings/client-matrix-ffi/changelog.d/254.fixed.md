Android builds now use ring as the rustls crypto provider instead of aws-lc-rs,
which crashed at client initialisation on some Android targets and emulators
(16 KB page size arm64 among them). The provider is chosen per target rather
than through the default feature set: `rustls-aws-lc-rs` is no longer a default
feature, and both it and the new `rustls-ring` stay available to override the
per-target choice.
