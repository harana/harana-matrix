`RoomPowerLevelsValues` gained `notification_room`, the level required to
trigger an `@room` notification, mapped from the `notifications` section of the
`m.room.power_levels` event.

`Client::set_pusher` gained a `disable_badge_count` parameter (defaulting to
`false`), which signals per
[MSC4076](https://github.com/matrix-org/matrix-spec-proposals/pull/4076) that
the client computes its own badge counts, so the homeserver stops sending
high-priority pushes whose only purpose is to update the unread count. It
applies to HTTP pushers only.

`NotificationRoomInfo` gained `can_send_message`, telling a client whether the
current user may send a message in the room, and hence whether a reply action
can be offered on the notification.

`RoomInfo` gained `default_notification_mode`, the mode a room falls back to
when the user hasn't defined one for it. Alongside
`cached_user_defined_notification_mode`, it lets a client tell whether a room is
following the account default, and render mute and notification indicators
correctly.
