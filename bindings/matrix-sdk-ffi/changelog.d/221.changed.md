[**breaking**] `RoomInfoListener::call` now receives the reasons why the
`RoomInfo` changed, as a `Vec<RoomInfoUpdateReason>`, so consumers can react
selectively instead of comparing every field with the previous value. The list
is empty for the initial value emitted by `Client::subscribe_to_room_info`, and
contains `RoomInfoUpdateReason::Unknown` when the change cannot be attributed to
a more precise reason. `Room::subscribe_to_room_info_updates` is now driven by
the same notable-update stream as `Client::subscribe_to_room_info`.
