`setLogEventListener` and `clearLogEventListener` let a consumer receive every
log statement the SDK emits, as a `LogRecord` carrying level, target, message,
file, line and timestamp. The SDK owned its log writers, so there was no way to
route logs to a platform logger or collect them in a test harness. The listener
is delivered alongside the existing stdout and file writers rather than
replacing them, and the filter configured by `initPlatform` still applies.
