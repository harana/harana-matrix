Expose the state and account data the SDK already holds: `Room::get_state_event`
and `Room::get_state_events` read arbitrary state events out of a room's state
as JSON strings, and `Room::account_data` / `Room::set_account_data` read and
write room account data. Global account data was already reachable through
`Client::account_data` and `Client::set_account_data`.
