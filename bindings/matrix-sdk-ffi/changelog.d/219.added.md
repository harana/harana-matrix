Expose the state and account data the SDK already holds: `Room::state_events`
reads every state event of a type out of a room's state as JSON strings,
alongside the `Room::state_event` that reads one, and
`Room::account_data` / `Room::set_account_data` read and write room account
data. Global account data was already reachable through `Client::account_data`
and `Client::set_account_data`.
