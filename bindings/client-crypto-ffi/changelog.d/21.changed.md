The Apple crypto framework is now built with
`cargo xtask swift build-crypto-framework`, replacing the
`bindings/apple/build_crypto_xcframework.sh` shell script. The task shares the
build, lipo and xcframework steps with the full SDK's `build-framework`, takes
`--only-ios`, `--profile`, `--sequentially` and the deployment target options,
and produces the same `generated/MatrixSDKCryptoFFI.zip`.
